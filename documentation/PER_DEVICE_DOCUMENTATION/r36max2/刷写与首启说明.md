# R36 Max 2 装 Ubuntu 26.04 —— v19

## 一句话

**GPU 上层也验完了**：panfrost + Mesa + GBM + EGL + GLES 3.1 全通，1024×768 着色器动画能扫到屏上。
v19 把这轮在线装的东西（编译链、mesa/GBM 开发头、两个 GPU 程序）全部固化，重刷即可复现。

## 刷 v19

**r36max2-ubuntu-v19.img.xz**（204,724,528 B = 195.2 MB，镜像本体不入库，
校验记录在 [distributions/](../../../distributions/README.md)）
sha256 `ea1aa41ea33d56b467d2100c333baf8d6c0f55c7cd00b99b63e56a8d018cb282`

刷那张 **64GB 卡**，**别碰 Lexar 128GB**（ArkOS + 你的 ROMS）。Rufus / balenaEtcher 直接选
`.img.xz`；Rufus 问"要使用 DOS 兼容分区吗"选**否**；插 **TF1**。写入耗时和之前一样（镜像
体积涨了是因为把 gcc/mesa 开发头打进来了，写到卡上的仍然是 2176 MiB）。

⚠️ **不急的话可以先不刷**：你现在这张卡（v17 + 这轮在线改动）内容上和 v19 基本一致，
刷 v19 的意义是"从零可复现"和"换卡时不用重做环境"。

刷完第一次开机 40 秒后：

```bash
ssh ubuntu@r36max2.local        # 密码 ubuntu（root 同）—— 第一件事 sudo passwd 改掉
sudo r36-expand-root            # 在线扩到整卡，不用重启
sudo r36-glcheck                # 看屏幕上有动画 = GPU 上层 OK
```

## 卡上的开关（在 BOOT 分区新建空文件即可，删掉恢复；卡里也有一份 `r36-switches.txt`）

| 文件 | 作用 |
|---|---|
| `wifi.txt` | **换网络就用它**：两行 `SSID=...` / `PSK=...`，开机 30 秒内、之后每分钟检查一次，自动写进 wpa_supplicant 并重连，结果回写到 `wifi-status.txt`（连上给 IP，连不上附热点清单）。参考卡里的 `wifi-example.txt` |
| `rescue` | 以 `rescue.target` 启动 |
| `noscreen` | 关掉屏幕上每 30 秒重画的状态页 |
| `r36-log` | 立刻再写一份状态报告到 `r36-boot.txt` |
| `use-boot-fw` | 改用 BOOT 分区 `fw\aic8800DC\` 里那套（Radxa bundle 版）WiFi 固件并重载驱动 |
| 把 `boot-usbhost.ini` 改名成 `boot.ini` | 换设备树，打开第二组 USB 主机控制器（试外接 USB 设备） |

## 如果是别人刷这张卡（WiFi 环境不一样）

这台板子**没有键盘、没有串口、Type-C 也不能当主机口**，所以没法在设备上输 WiFi 密码。
v19 起解决办法是卡上的 `wifi.txt`：

1. 刷完卡，Windows 里打开 BOOT 分区，把 `wifi-example.txt` 复制一份改名 `wifi.txt`，
   用记事本改成自己家的 SSID 和密码，保存。
2. 插进掌机开机，等 30–60 秒。屏幕上状态页的 `wlan0 ip` 会直接显示拿到的地址。
3. 不放心就把卡插回电脑看 `wifi-status.txt`：`OK: connected to ..., IPv4=...`，
   或者 `FAIL: cannot associate ...` 后面跟着它扫到的热点清单（密码错还是名字错一眼能分辨）。
4. 改密码/换路由器只要再编辑 `wifi.txt`，一分钟内自动生效，不用重刷。

注意 `wifi.txt` 是明文放在 FAT 分区上的（FAT 没有权限位），设备里只保存它的 PBKDF2 哈希；
公共环境用完记得删掉。要做一个**完全不带凭据**的镜像给别人：构建时
`R36_BAKE_WIFI=0 bash scripts/build-rootfs.sh`，这样镜像里连我自己家的网络都不会出现。

设备开机 40 秒后（之后每 2 分钟）把完整状态写到 **`BOOT:\r36-boot.txt`**，状态页画在 tty1。
电脑侧还有 `E:\ubuntu\build\shot.sh`：把显存抓回来转 PNG，不用拍照片。

## 还没做的

1. **唤醒链路**：`echo mem > /sys/power/state` 进得去，但电源键和 RTC 闹钟都叫不醒（表现为白屏，
   只能长按强制关机或 reset）。厂商 BSP 依赖主线没有的私有绑定（`rockchip,sleep-mode-config`、
   `rk817_slppin_*` 引脚复用），主线 `rk8xx` 的 PMIC 中断有没有注册成 wakeirq 也要查。
   修好之前睡眠保持 mask —— 短按电源键现在什么都不做，长按 3–5 秒仍是硬件强制关机。
   **以后测睡眠前一定先设 RTC 闹钟**：`echo +60 > /sys/class/rtc/rtc0/wakealarm`。
2. 按键的用户空间映射表（事件已齐全，缺的是给前端/桌面用的配置）。
3. 蓝牙固件超时；VPU 硬解主线不支持 px30/rk3326，只能软解。
4. 想回 EmuELEC：拔掉这张卡就是 eMMC 里的原系统（全程未动）。之前在 EmuELEC 上为调试关过的
   休眠与 WiFi 省电，回那边记得恢复：

```bash
systemctl unmask suspend.target sleep.target hibernate.target hybrid-sleep.target suspend-then-hibernate.target
iw dev wlan0 set power_save on
```
